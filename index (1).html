Google Sheets setup

  1. Create or open a Google Sheet.
  2. Choose Extensions → Apps Script.
  3. Replace the editor contents with the supplied google-apps-script.gs file and save it.
  4. Choose Deploy → New deployment → Web app. Execute as Me and allow access to Anyone.
  5. Copy the web app URL ending in /exec, paste it above, enable sync, and save.

Keep the web app URL private. It acts as the app's permission to add rows to your sheet.
